# Approved Stitch Dashboard References

These files are visual and structural references for Crystal Code Quest.

## Primary laptop direction

- Child dashboard: Learning Studio
- Parent dashboard: Learning Studio

## Supplemental responsive references

- Child tablet portrait: Quest Journey
- Parent tablet landscape: Command Centre

The tablet references provide useful responsive composition ideas but come from
different Stitch design directions. The implementation should retain one
consistent Crystal Code Quest design system across all viewports.

## Implementation rules

- Screenshots are the primary visual reference.
- HTML files are reference material only.
- Do not copy the exported HTML directly into the application.
- Reuse the existing Next.js, React, Tailwind, authentication and database
  architecture.
- Do not introduce remote runtime assets or dependencies from the Stitch HTML.
- Preserve accessibility, truthful mocked labels and responsive behaviour.
